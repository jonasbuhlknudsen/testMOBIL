<product_requirements>
The Nerdværket application is an Expo mobile app controlling an iDot-3 LED Pixel Screen via BLE, aiming for LOY PLAY app parity.
**Core Functional Requirements:** BLE connectivity (Service UUID FEE7, Write 36F5, Notify 36F6, plus new UART and Fallback profiles), Screen Control (Solid Color, Animations, Image Transfer with SOF/CHUNK/EOF, CRC16, Games, Text Scroller, Power, Brightness).
**User Experience:** LOY PLAY-inspired UI, tab-based navigation (Connect, Visuals, Media, Games, Settings), branding (Nerdværket logo, dark theme, gradients, blur-cards, clear typography, large touch targets, Ionicons), ACK badges, notify logs, error popups.
**Technical Constraints:** Development Builds for BLE, byte processing, base64, robust ACK/timeout/retry.
**Recent Additions & Future Scope (LOY PLAY-paritet):**
*   **BLE Foundation:** Multi-profile support (UART, FFF0 fallback), MTU 247, auto-reconnect, GATT queue, error handling. Filtering on YS name or service UUIDs.
*   **Protocol Layer:** Transport-agnostic, ASCII/UTF-8/HEX ↔ bytes, framing/reassembly, heartbeat, configurable checksum, JSON command schema ().
*   **UI Features:** Color wheel (HSV, CCT, RGB/W/CCT), gamma, brightness/speed sliders, power on/off. IC/Pixel setup (type, count, segments, power-limit). Scenes & Effects (presets, editor, save/load). DIY Editor (keyframes, palettes, image/text to LED). Music/Mic modes (real-time FFT, beat detection). Camera/Image modes (color sampler). Timers & Schedules (sleep/wake, daily/weekly, sunrise/sunset). Groups & Sync (broadcast, leader-follower). OTA/DFU (stub). Backup/Restore (JSON). Multi-language (Danish/English) & Theme (light/dark).
*   **UI Screens:** Scan, Device, Groups, Settings, Logs.
*   **Permissions:** Android (BLE_SCAN, BLE_CONNECT, RECORD_AUDIO), iOS (CoreBluetooth, Microphone).
*   **Stability:** Global GATT queue, timeouts, retries, MTU logging.
